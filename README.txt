FEIRA DO CONHECIMENTO CIENTÍFICO - SITE COM INTEGRANTES

Arquivos:
- index.html: conteúdo principal
- styles.css: visual e responsividade
- script.js: menu para dispositivos móveis

Como abrir:
1. Extraia o arquivo ZIP.
2. Abra o arquivo index.html em um navegador.

O site contém:
- Apresentação da feira
- 4 projetos
- Seção com os integrantes de cada grupo
- Área para data, horário e local
- Layout responsivo para celular e computador

Personalize os campos de data, horário e local no arquivo index.html antes da publicação.
